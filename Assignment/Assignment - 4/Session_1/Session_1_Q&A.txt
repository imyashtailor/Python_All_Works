1.) Explore the folder structure of your 'foodiehub_project' and write down the purpose of each key file: 
manage.py, settings.py, urls.py, wsgi.py, and asgi.py.<br><br><em><strong>Hint:</strong> 
Check the official Django documentation or use ChatGPT to help you describe each file's role.</em>
=>

below the explanation of structure :-

1. manage.py :- 
=> runs django command 
Examples :-
python manage.py runserver
python manage.py migrate
python manage.py createsuperuser.

Remember :- Project Manager


2. settings.py
=> Stores all project settings.
includes :-
Database
Installed apps
Time zone
Templates
static files
security settings

Remember :- Project Configuration

3. urls.py 
=> Connects URLs to Views.
=> decides which page open when user visits a specific URL
Example :-

urlpatterns = [
    path("admin/",admin.site.urls),
]

Remember :- URL Traffic Controller

4. wsgi.py :-
=> used when deploying the project on production server
=> helps the web server communicate with django using the WSGI standard.

Remember :- production server gatway(Synchronous)

5. asgi.py
=> used for asynchronous features such as :-
1. websocket
2. Live chat
3. Notifications
4. Real-time applications

Remember :- Modern Async Gatway

Flask :-
